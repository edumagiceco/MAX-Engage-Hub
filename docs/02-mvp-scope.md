# MVP Scope

## 1. MVP의 원칙

MVP 단계에서는 `고객 DB 통합`, `첫 문의 대응`, `교육 운영`, `결과물 관리`, `사례 활용`, `블로그 메일링`에 집중한다.

다음은 하지 않는다.

- 별도 CRM 구축
- 고급 마케팅 자동화
- AI 기반 추천 엔진 고도화
- 자동 제안서 생성 파이프라인
- 복잡한 이벤트 버스나 CDP 도입

## 2. MVP 핵심 기능

### A. 통합 리드 수집

- 교육 문의, Contact, AX 진단, AX 맞춤 추천 폼 수집
- 이메일 기준 기본 중복 병합
- 유입경로 저장
- 마케팅 수신 동의 저장

### B. 고객/문의 관리

- 고객 목록 조회
- 고객 상세 조회
- 문의 이력 타임라인
- 리드 상태 관리
- 담당자 메모와 후속 액션 날짜 관리

권장 상태값:

- `new`
- `in_review`
- `contacted`
- `meeting_scheduled`
- `proposal`
- `won`
- `lost`
- `nurturing`

### C. AX 진단 및 추천 저장

- 진단 응답 저장
- 점수 또는 maturity level 저장
- 규칙 기반 추천 결과 저장
- 상담자가 볼 수 있는 요약 생성

추천 카테고리 예시:

- `education`
- `consulting`
- `rag`
- `ocr`
- `workflow_automation`

### D. 사례/성과 라이브러리

- 사례 등록
- 산업/부서/문제/솔루션 기준 검색
- 정량/정성 성과 기록
- 상담 시 관련 사례 연결

### E. 교육 운영 및 결과물 관리

- 교육 프로그램 등록
- 교육 회차 및 일정 관리
- 참여 회사/참여자 관리
- 교육 결과물 등록
- 후속 액션 아이템 저장

교육 결과물 예시:

- 진단 리포트
- 실습 산출물
- 액션 플랜
- 부서별 적용 과제
- 멘토링 결과 메모

### F. 사례 후보 및 사례 전환

- 교육 결과물 또는 프로젝트 결과를 사례 후보로 등록
- 사례 후보 검토
- 공개 가능한 사례로 승인
- 상담/제안에 재사용

### G. 컨설팅/솔루션 프로젝트 기록

- 프로젝트 생성
- 프로젝트 유형과 상태 관리
- 진행 메모 저장
- 중간 산출물 저장
- 종료 요약 저장

### H. 블로그 메일링

- 블로그 글 등록 또는 발행 정보 입력
- 고객 태그/동의 여부 기반 수신 대상 선택
- 메일 발송
- 오픈/클릭/수신거부 반영

## 3. 사용자 시나리오

### 시나리오 1: 교육 문의

1. 사용자가 교육 문의 폼 제출
2. 고객 레코드 생성 또는 기존 고객에 문의 이력 추가
3. 운영자가 리드 상태를 `new`로 확인
4. 담당자가 메모를 남기고 후속 연락 진행

### 시나리오 2: AX 진단 후 상담 연결

1. 사용자가 진단 수행
2. 진단 결과와 추천 결과 저장
3. 담당자가 고객 상세에서 결과 확인
4. 관련 사례를 붙여 첫 상담 진행

### 시나리오 3: 교육 운영 및 결과물 축적

1. 운영자가 교육 프로그램과 회차 등록
2. 참여 회사와 참여자 연결
3. 교육 중 진단 리포트, 실습 산출물, 액션 플랜 저장
4. 교육 종료 후 후속 상담 또는 솔루션 제안으로 연결
5. 우수 결과물은 사례 후보로 전환

### 시나리오 4: 프로젝트 실행 및 종료 기록

1. 교육 또는 상담 이후 프로젝트 생성
2. 프로젝트 범위와 상태 저장
3. 진행 메모와 산출물 누적
4. 종료 시 성과 요약 기록
5. 사례 후보 전환 여부 판단

### 시나리오 5: 블로그 메일 nurture

1. 운영자가 블로그 글 발행
2. 관련 태그 고객 세그먼트 선택
3. 메일 발송
4. 오픈/클릭 반응 확인
5. 반응이 높은 고객을 후속 상담 대상으로 분류

## 4. MVP 제외 범위

- 다중 조직/다중 권한 체계
- 고급 보고서 자동 생성
- AI 챗봇 기반 문의 응대
- 외부 SaaS CRM 양방향 동기화
- 다단계 drip campaign builder
- 고급 리드 스코어링 모델

## 5. MVP 완료 정의

아래가 가능하면 MVP는 완료로 본다.

- 모든 문의 채널이 한 DB로 들어온다.
- 고객별 문의/진단/추천/메일 반응 이력이 한 화면에 모인다.
- 교육 회차와 교육 결과물이 고객 또는 회사 기준으로 연결된다.
- 컨설팅/솔루션 프로젝트 이력이 고객 또는 회사 기준으로 연결된다.
- 유사 사례를 검색해 상담에 활용할 수 있다.
- 교육 결과물을 사례 후보로 전환할 수 있다.
- 프로젝트 종료 결과를 사례 후보로 전환할 수 있다.
- 블로그 글을 고객 세그먼트에게 메일로 보낼 수 있다.
- 기본 전환 지표를 관리자 화면에서 확인할 수 있다.
