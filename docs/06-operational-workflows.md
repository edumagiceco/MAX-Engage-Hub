# Operational Workflows

이 프로젝트는 하나의 직선형 파이프라인이 아니라, 서로 연결되는 여러 운영 워크플로우를 가진다.

핵심은 `유입`, `진단`, `교육`, `프로젝트`, `사례`, `콘텐츠`, `성과`가 분절되지 않도록 하는 것이다.

## 1. 워크플로우 맵

### Workflow 1. 유입 및 리드 생성

- 블로그
- 교육 문의
- 일반 Contact
- AX 진단
- AX 맞춤 추천

결과:

- 고객 생성 또는 병합
- 유입경로 저장
- 초기 태그 부여

### Workflow 2. 첫 문의 및 첫 상담

- 신규 리드 확인
- 기본 맥락 파악
- 진단 결과 또는 관심 주제 확인
- 상담 준비
- 첫 미팅 또는 후속 연락

결과:

- 리드 상태 변경
- 상담 메모 저장
- 다음 액션 일정 생성

### Workflow 3. AX 진단 및 처방

- 진단 수행
- 점수화 또는 수준 분류
- 교육/컨설팅/솔루션 추천
- 초기 제안 방향 정리

결과:

- 진단 리포트
- 추천 결과
- 상담용 요약

### Workflow 4. 교육 운영

- 교육 프로그램 설계
- 회차 등록
- 참여자 등록
- 진행 메모
- 결과물 저장
- 교육 종료 처리

결과:

- 출석/참여 정보
- 실습 결과물
- 액션 플랜
- 부서별 과제

### Workflow 5. 교육 후 후속 전환

- 교육 결과 리뷰
- 후속 상담
- 컨설팅/솔루션 기회 식별
- 추가 제안 또는 파일럿 연결

결과:

- 후속 기회 생성
- 차기 미팅 연결
- 우선순위 높은 고객 분류

### Workflow 6. 컨설팅/솔루션 프로젝트 실행

- 프로젝트 생성
- 범위와 목표 정리
- 진행 메모 저장
- 중간 산출물 저장
- 종료 결과 정리

결과:

- 프로젝트 이력
- 종료 요약
- 사례 전환 후보

### Workflow 7. 사례 후보 생성 및 승인

- 교육 결과물 검토
- 프로젝트 성과 검토
- 사례 후보 등록
- 공개 가능성 검토
- 승인 후 사례 라이브러리 반영

결과:

- 재사용 가능한 레퍼런스 자산
- 산업/부서별 검색 가능한 사례

### Workflow 8. 사례 기반 상담/제안

- 고객 문제 확인
- 유사 사례 검색
- 상담 중 사례 제시
- 제안서/후속 설명에 활용

결과:

- 상담 설득력 강화
- 제안 품질 개선

### Workflow 9. 블로그 메일링 및 nurture

- 블로그 글 발행
- 관련 태그 고객 선택
- 메일 발송
- 반응 추적
- 반응 고객 후속 분류

결과:

- 재활성화 리드
- 관심 주제별 고객 세분화

### Workflow 10. 성과 리뷰 및 개선

- 리드 생성 성과 확인
- 상담 전환 확인
- 교육 운영 성과 확인
- 프로젝트 운영 성과 확인
- 사례 활용 성과 확인
- 메일링 성과 확인
- 개선 포인트 도출

결과:

- 다음 캠페인 방향
- 다음 교육 기획 방향
- 다음 영업 대응 개선안

## 2. 핵심 연결 포인트

### 진단에서 교육으로

진단 결과는 교육 제안의 근거가 된다.

### 교육에서 사례로

교육 결과물은 사례 후보가 된다.

### 사례에서 상담으로

사례는 후속 상담과 제안의 신뢰 근거가 된다.

### 블로그에서 상담으로

블로그 반응은 다시 상담 우선순위를 조정하는 입력이 된다.

## 3. MVP에서 반드시 지원해야 할 워크플로우

우선 구현 대상:

- 유입 및 리드 생성
- 첫 문의 및 첫 상담
- AX 진단 및 처방
- 교육 운영
- 컨설팅/솔루션 프로젝트 실행
- 사례 후보 생성 및 승인
- 블로그 메일링 및 nurture
- 성과 리뷰

후순위 구현 대상:

- 복잡한 승인 체계
- 자동 제안서 조립
- 고급 점수 모델
- 조직 단위 권한 분리
